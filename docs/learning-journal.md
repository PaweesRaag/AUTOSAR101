# AUTOSAR101 Learning Journal

This file preserves the learning roadmap and study notes that informed the implementation.

## Learning Direction

The project is intentionally implementation-first. Theory is documented here; the root README focuses on what the software actually implements.

## Planned Modules

1. AUTOSAR Classic foundations
2. Software Components, ports and interfaces
3. RTE communication
4. COM and PDU handling
5. PduR / CanIf / CAN simulation
6. Diagnostics (UDS, DCM, DEM)
7. SecOC and freshness handling
8. Crypto abstraction and AES-CMAC experiments
9. NvM / memory-stack simulation
10. Test automation and CI
11. Optional Ethernet / SOME-IP extensions
12. Reverse-engineering experiments on generated/simulated binaries

## Engineering Rule

Each module should move from concept → interface → implementation → test → documented data flow.

The project is an educational simulation and is not intended to claim production AUTOSAR compliance or certification.
